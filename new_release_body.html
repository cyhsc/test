Speed Test Server

A Bumblebee CPE can now be used as a Speed Test Server. Any browser that can reach the CPE can run a speed test to it. For example, a service provider can run a speed test from a colocation facility to the CPE.

To run a test, click Internet CPE on the left navigation menu. Select a CPE and click Actions -> Start Speed Test Server. Click GO to run the test from your browser, or copy the link to run it from another location.

Note: the link expires after 15 minutes. The CPE accepts speed test connections only during that window.

To learn more, check out Bumblebee Speed Test Server.

WAN Failover Test

WAN Failover Test lets you simulate a WAN link failure remotely, without needing on-site personnel to unplug the WAN Ethernet cable. When the configured interval expires, the WAN interface resumes operation. This controlled outage lets you test failover handling and prepare for disaster recovery.

To configure, click Internet CPE on the left navigation menu. Select a CPE and click Actions -> WAN Failover Test. Enter the test duration in minutes and click Start Test. When the timer expires, normal operation resumes. To end the test early, click End Test.

Note: this test takes the live WAN link down for the duration you set. End Test requires a cellular out-of-band connection on the CPE; without one, the WAN resumes when the timer expires.

BN-CPE-10GF(C) Ready for Order

BN-CPE-10GF and BN-CPE-10GFC are new product codes now available to order. Both have 2x 10G SFP+ ports, 6x 2.5G RJ45 ports and dual power supplies. The BN-CPE-10GFC adds an integrated 5G cellular modem. Both support the same software features as the 1000 series.

To create a CPE, click Internet CPE. Click Create Device and, in the Product Code field, select BN-CPE-10GF or BN-CPE-10GFC.

Create CPE Enhancements

  • Clone Device saves you time when creating a new CPE by copying all fields of a selected CPE, so you don’t have to enter every field. To configure, select a CPE and click Actions -> Clone Device.

  • Checkbox for identical addresses saves you from typing the shipping address when it is the same as the site address. To configure, click Create Device. In the Shipping Address section, check the box if the shipping address is the same as the site address.

Down Detection Timer Enhancements

Down Notification Interval is now called Down Detection Timer. The setting works the same way as before.

  • Entity Down Detection Timer is a new option to apply the Down Detection Timer across all sites (CPEs assigned to the entity) by configuring the timer at the entity level. To configure, go to Entities on the left navigation menu. Select an entity and click Actions -> Edit Down Detection Timer. Enter the time in minutes and click Save.

  • Mute Link Alerts Indefinitely is a new option to stop alert messages for a specific site until you turn the mute off. It complements the existing option to mute alerts for a set number of hours, after which they turn back on automatically. To configure, click Internet CPE on the left navigation menu. Select a CPE and click Actions -> Edit Down Detection Timer. Check the box Mute Link Alerts, then check Mute Indefinitely. For more details, check out Down Detection Timer.

BN-CPE-IP Enhancements

  • Test Service lets you run an IP reachability test before and after activating the service. To perform the test, select the CPE (with the product code BN-CPE-IP) and click Actions -> Test Service.

  • Clone Device is now also available for BN-CPE-IP.

  • Assign Entity assigns a BN-CPE-IP site to an entity. To configure, select the CPE and click Actions -> Assign Entity.

App Visibility Enhancements

Bumblebee App Visibility Dashboard provides L7 application visibility and uses AI to classify applications into categories. You can now specify the percentage of traffic to capture and analyze. In a high-performance environment, statistical sampling is a realistic way to capture traffic and still get a good representation of the applications going through the CPE.

To configure, click Internet CPE. Select the CPE. Click Actions -> Edit App Visibility. Check the box Advanced. Enter a number from 5 to 100, to capture 5% to 100% of the traffic. The default is 100%.

Speed Test Enhancements

  • Ookla Server ID List: the Advanced option in Speed Test now provides a list of Ookla server IDs to choose from, in addition to entering a specific server ID. The list shows the six servers geographically nearest to the CPE. To run an advanced speed test, click Internet CPE on the left navigation menu. Select a CPE and click Actions -> Run Speed Test -> Ookla Speedtest -> Advanced -> Use a specific Ookla speed test server. Select a server from the dropdown, or enter an ID if you know it.

  • Display Traceroute: after an advanced speed test is completed, you can view the traceroute to the selected Ookla server. This helps service providers identify the routers in the data path when troubleshooting underperforming routers. To view the traceroute after a test is complete, click to expand View Traceroute.
